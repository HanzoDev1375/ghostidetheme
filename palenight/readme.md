# Palenight

The blue-purple Material Palenight theme.

## Features
- Material palenight background `#292d3e`
- Signature colors: blue `#82aaff`, cyan `#89ddff`, pink `#ff5370`, purple `#c792ea`
- Material 3 color system based on Palenight pink

## Apply
1. Open `palenight.gth` in the File Manager.
2. Tap **Apply**.
