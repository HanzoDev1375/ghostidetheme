# Night Owl

The beautiful Night Owl theme by Sarah Drasner.

## Features
- Deep blue background `#011627`
- Signature colors: blue `#82aaff`, cyan `#7fdbca`, green `#addb67`, purple `#c792ea`
- Material 3 color system based on Night Owl blue

## Apply
1. Open `night-owl.gth` in the File Manager.
2. Tap **Apply**.
