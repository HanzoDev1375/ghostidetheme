# GitHub Dark

The official GitHub Dark default theme.

## Features
- GitHub dark background `#0d1117`
- Signature colors: blue `#58a6ff`, red `#ff7b72`, green `#7ee787`, purple `#d2a8ff`
- Material 3 color system based on GitHub blue

## Apply
1. Open `github-dark.gth` in the File Manager.
2. Tap **Apply**.
