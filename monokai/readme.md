# Monokai

The classic Monokai theme — dark background with bright, vivid syntax.

## Features
- Dark background `#272822`
- Vivid syntax: red `#f92672`, green `#a6e22e`, blue `#66d9ef`
- Material 3 color system based on Monokai green

## Apply
1. Open `monokai.gth` in the File Manager.
2. Tap **Apply**.
