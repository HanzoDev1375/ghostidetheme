# Catppuccin Mocha

The soothing, pastel Catppuccin Mocha theme.

## Features
- Mocha base background `#1e1e2e`
- Signature colors: lavender `#b4befe`, pink `#f5c2e7`, blue `#89b4fa`, teal `#94e2d5`
- Material 3 color system based on Catppuccin lavender

## Apply
1. Open `catppuccin-mocha.gth` in the File Manager.
2. Tap **Apply**.
