# Ayu Mirage

Mid-tone, eye-friendly colors from the Ayu Mirage palette.

## Features
- Mirage background `#1f2430`
- Signature colors: blue `#73d0ff`, green `#bae67e`, yellow `#ffd580`, purple `#d4bfff`
- Material 3 color system based on Ayu green

## Apply
1. Open `ayu-mirage.gth` in the File Manager.
2. Tap **Apply**.
