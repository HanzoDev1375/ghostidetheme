# VSCode Dark

The classic Visual Studio Code Dark+ theme.

## Features
- Dark background `#1e1e1e`
- Signature colors: blue `#569cd6`, orange `#ce9178`, yellow `#dcdcaa`, cyan `#9cdcfe`
- Material 3 color system based on VSCode blue

## Apply
1. Open `vscode-dark.gth` in the File Manager.
2. Tap **Apply**.
