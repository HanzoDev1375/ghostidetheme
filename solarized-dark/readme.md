# Solarized Dark

The meticulously crafted Solarized Dark palette by Ethan Schoonover.

## Features
- Base03 background `#002b36`
- Signature colors: blue `#268bd2`, cyan `#2aa198`, green `#859900`, orange `#cb4b16`
- Material 3 color system based on Solarized blue

## Apply
1. Open `solarized-dark.gth` in the File Manager.
2. Tap **Apply**.
