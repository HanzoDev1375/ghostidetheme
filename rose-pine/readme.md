# Rose Pine

The elegant, soft Rose Pine theme.

## Features
- Deep base background `#191724`
- Signature colors: rose `#eb6f92`, gold `#f6c177`, foam `#9ccfd8`, pine `#31748f`
- Material 3 color system based on Rose Pine iris

## Apply
1. Open `rose-pine.gth` in the File Manager.
2. Tap **Apply**.
