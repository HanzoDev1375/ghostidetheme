# Material Dark

The popular Material Theme inspired by Google Material Design.

## Features
- Material dark background `#263238`
- Signature colors: blue `#82aaff`, cyan `#89ddff`, red `#ff5370`, purple `#c792ea`
- Material 3 color system based on Material teal

## Apply
1. Open `material-dark.gth` in the File Manager.
2. Tap **Apply**.
