# Everforest

The comforting, warm-green Everforest theme.

## Features
- Warm dark background `#2d353b`
- Signature colors: green `#a7c080`, blue `#7fbbb3`, red `#e67e80`, yellow `#dbbc7f`
- Material 3 color system based on Everforest green

## Apply
1. Open `everforest.gth` in the File Manager.
2. Tap **Apply**.
