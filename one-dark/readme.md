# One Dark

The beloved One Dark theme from Atom / VS Code.

## Features
- Dark background `#282c34`
- Signature colors: blue `#61afef`, red `#e06c75`, green `#98c379`, cyan `#56b6c2`
- Material 3 color system based on One Dark blue

## Apply
1. Open `one-dark.gth` in the File Manager.
2. Tap **Apply**.
