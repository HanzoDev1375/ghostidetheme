# Gruvbox

The classic warm-dark Gruvbox theme.

## Features
- Warm dark background `#282828`
- Signature colors: red `#fb4934`, green `#b8bb26`, yellow `#fabd2f`, blue `#83a598`
- Material 3 color system based on Gruvbox yellow

## Apply
1. Open `gruvbox.gth` in the File Manager.
2. Tap **Apply**.
