# Darcula

The JetBrains Darcula theme (IntelliJ / Android Studio).

## Features
- Darcula background `#2b2b2b`
- Signature colors: orange `#cc7832`, blue `#6897bb`, green `#6a8759`, purple `#9876aa`
- Material 3 color system based on Darcula blue

## Apply
1. Open `darcula.gth` in the File Manager.
2. Tap **Apply**.
