# High Contrast

Maximum-contrast theme for accessibility — pure black & white with vivid accent colors.

## Features
- Pure black background `#000000`, pure white text `#ffffff`
- Vivid accents: cyan `#00ffff`, yellow `#ffff00`, green `#00ff00`
- Material 3 color system built for maximum readability

## Apply
1. Open `high-contrast.gth` in the File Manager.
2. Tap **Apply**.
